titre: Un verbe ou nom désignant le cri d'un animal
# Verbes (et noms correspondants) qui désignent le cri ou le son émis par un animal : aboyer/aboiement, miauler/miaulement… Les onomatopées (« meuh », « cocorico ») et les verbes génériques (crier, chanter) ne sont pas retenus. Verbes très proches regroupés (piauler/piailler, hululer/ululer, meugler/beugler, craqueter/claqueter).
1: Aboyer = Aboiement = Aboi; Miauler = Miaulement = Miaou; Bêler = Bêlement; Hennir = Hennissement; Rugir = Rugissement; Meugler = Meuglement = Beugler = Beuglement; Mugir = Mugissement; Coasser = Coassement; Hurler = Hurlement; Grogner = Grognement; Ronronner = Ronronnement; Barrir = Barrissement; Braire = Braiment; Siffler = Sifflement
2: Croasser = Croassement; Glousser = Gloussement; Caqueter = Caquètement; Cancaner = Cancan; Roucouler = Roucoulement; Piauler = Piaulement = Piailler = Piaillement; Pépier = Pépiement; Gazouiller = Gazouillis; Bourdonner = Bourdonnement; Striduler = Stridulation; Hululer = Hululement = Ululer = Ululement; Coqueriquer; Feuler = Feulement; Couiner = Couinement; Grouiner = Grouinement; Bramer = Bramement; Jacasser = Jacassement; Vrombir = Vrombissement; Glapir = Glapissement; Japper = Jappement; Chuinter = Chuintement; Gronder = Grondement; Cacarder = Cacardement; Chevroter = Chevrotement
3: Glatir = Glatissement; Blatérer = Blatèrement; Craqueter = Craquètement = Claqueter = Claquètement; Coucouler; Grésillonner = Grésillement; Turluter = Turlutement; Huer = Huement
4: Raire = Réer = Rairement; Cacaber = Cacabement; Zinzinuler
5: Rauquer = Rauquement; Carcailler = Carcaillement
